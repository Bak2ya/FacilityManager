# FacilityManager

학교 시설관리 기준도를 중심으로 공간, 잠금, 소방·방재, 냉난방/설비, 공사이력 등을 조회·관리하기 위한 로컬 데이터 기반 웹앱입니다.

현재 버전: **v0.10.0 · Build 10**

## 배포 구조

- 앱 코드: 학교별 GitHub Pages
- 실제 시설 데이터: 학교 내부에서 별도 배포하는 FACDB
- 최신 DB 기준: GitHub Pages의 `latest-db.json`
- 실제 FACDB, 운영 암호, 잠금정보는 공개 GitHub 저장소에 올리지 않습니다.

## Build 10 핵심

- 데스크톱 우측 패널을 **조회 / 표시 / 관리 / 설정** 4개 탭으로 재구성
- 모바일 메뉴도 동일한 4개 분류를 사용하고, 조회만 기본 펼침
- 표시 탭에서 도면 요소·시설 레이어와 호실번호/호실명/관리부서/면적, 글자 크기 제어
- 관리 탭의 도면 진입점은 **도면 편집** 하나로 단순화
- 설정 탭에 테마·레이아웃·데이터 관리·홈 화면 추가·사용법·단축키·GitHub·개발자 연락을 통합
- 하단 고정 DB 배포 상태 박스를 제거하고 상단 **DB 배포 필요 / 새 DB 있음** 배지를 클릭해 상세 경고를 다시 확인하도록 변경
- DXF 레이어 목록의 체크 시 스크롤 위치가 위로 튀는 문제 수정
- DXF 레이어 **모두 표시 / 모두 숨김 / 반전 / 추천** 추가
- 레이어 검색, 요소 수/추정 분류, 임시 단독 보기 추가
- DXF 요소를 클릭하면 종류·레이어를 확인하고 해당 레이어를 단독 보기/가져오기 제외 가능
- 자동 레이어 분석은 추천에만 사용하며 자동 삭제하지 않음
