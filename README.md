# FacilityManager

완성된 건축/공간 도면을 중심으로 학교 시설정보를 조회·관리하는 웹앱입니다.

현재 버전: **v0.13.3 · Build 17**

## 바로 실행

- ▶ **[FacilityManager 바로 실행](https://bak2ya.github.io/FacilityManager/)**
- **[FacilityManager GitHub](https://github.com/Bak2ya/FacilityManager)**
- ▶ **[PieniPlan 바로 실행](https://bak2ya.github.io/PieniPlan/)**
- **[PieniPlan GitHub](https://github.com/Bak2ya/PieniPlan)**

> PieniPlan은 도면 제작·편집·트레이싱·공간 구조 정의를 담당하는 별도 프로젝트입니다.

## 역할 분리

- **FacilityManager**: 완성 도면 조회, 호실/부서/배정, 출입·잠금, 소방·설비, 공사 이력, 시설 데이터 운영
- **PieniPlan**: DXF/PDF/이미지 기반 도면 제작, 트레이싱, 도면 편집, 벽·문·창문·공간 정의, FACMAP 출력

FacilityManager는 PieniPlan이 내보낸 `.facmap`을 기존 공간과 비교하여 **바뀐 구조만 갱신하고 시설관리 업무 데이터는 유지**합니다.

## 작업 화면

- 화면 위 중앙 `건물명 · 층`에서 같은 건물의 층을 빠르게 변경
- 검색 / 출력 / 잠금정보 / 전체 보기 / 패널 버튼은 도면 위 floating controls
- 오른쪽 정보 패널은 완전히 접을 수 있음
- 패널을 닫은 채 공간을 선택하면 바로 옆에 빠른 정보 표시
- 패널이 열려 있으면 공간 선택 시 자동으로 `조회` 탭에서 상세 정보 표시
- 모바일과 데스크톱이 같은 선택/조회 원리를 사용
- 시설 데이터 연결 전에는 연결 화면만 보여 도면 조작 버튼이 노출되지 않음
- 도면 확대/축소는 휠·핀치를 기본으로 하고, 정확한 배율은 `표시 → 도면 배율` 슬라이더에서 조절

## 데이터와 오프라인 사용

- 실제 시설 데이터는 사용자가 불러온 FacilityManager 데이터 파일(`.facdb`)을 이 기기의 로컬 저장소에서 사용
- iPhone/iPad 파일 선택기에서 사용자 정의 `.facdb` 확장자가 차단되지 않도록 파일 선택 단계에서는 형식을 제한하지 않고, 앱이 파일 내용을 검증
- 설정의 버튼 명칭은 `데이터 불러오기 / 데이터 내보내기`로 통일
- `최신 여부 확인`은 현재 시설 데이터가 배포 기준과 비교해 최신인지 확인하는 기능
- `설정 → 데이터 → 오프라인 사용`에서 현재 기기를 오프라인 사용 가능하도록 명시적으로 준비할 수 있음
- 준비 상태는 `앱 파일 준비됨 / 시설 데이터 준비됨`으로 실제 상태를 구분해 표시
- 브라우저의 사이트 데이터·캐시·저장 공간을 삭제하면 다시 준비해야 할 수 있음
- 오프라인 중에는 서버의 최신 데이터 기준을 확인할 수 없으므로 최신 여부는 `확인할 수 없음`으로 표시

GitHub Pages에는 프로그램 코드와 공개 가능한 기준정보만 배포하고 실제 FACDB는 올리지 않습니다.
