# FacilityManager v0.15.0 · Build20

기본 실행·배포 환경은 **GitHub Pages(HTTPS)** 입니다. 별도 서버 설치가 필요하지 않습니다. 이번 ZIP은 배포 준비본이며 공개 사이트에 직접 게시하지 않았습니다.

1. GITHUB_PAGES.zip을 풀어 기존 앱 실행 파일을 갱신하세요. 기관의 site-config.json / latest-db.json 값은 보존하세요.
2. 앱에서 **PPKG 도면 열기** → 도면 확인 → **설정 → FACI 새로 만들기**.
3. 학교명·최상위 관리자 이름·암호를 정하고 **복구키를 별도 저장**하세요.
4. 공간 선택 → 편집에서 업무·출입·소방정보를 입력하세요. 관리 탭의 **FACI 파일 저장**으로 .faci를 내려받습니다.
5. 다음에는 **FACI 파일 열기**. 일반 조회는 암호 없이, 보호정보·수정은 해당 권한의 암호로 사용합니다.
6. 도면만 내보내기는 조회 탭의 **도면만 PPKG로 내보내기**. 원본 패키지별로 내보내 ID·범위·리비전을 보존합니다.
7. 오프라인은 설정 → 데이터 → **오프라인 사용 준비**. 로컬 저장은 파일 다운로드와 별개입니다.

## 전달물 3종

- GITHUB_PAGES.zip: 공개 가능한 정적 앱 실행 자산.
- LOCAL_SOURCE.zip: 최신 전체 소스와 필요한 테스트·설계 자료.
- HANDOFF.zip: 최신 상태·판단 이력·검증·다음 안내.

실제 학교 PPKG/FACI, 계정·복구키, 내부 도면 캡처, _AI_NOT_GITHUB 자료는 공개하지 마세요. 수동 업로드에는 .gitignore가 자동 적용되지 않습니다.

FACDB/FACMAP 입출력은 제거했습니다. 실제 사용한 레거시 원본이 없다는 사용자 결정에 따릅니다. 이전 구현은 역사 자료로만 보관합니다.
